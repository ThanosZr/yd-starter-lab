# YD LAB v3.0 — React Wiring & Motor Dynamics Studio

Διαδραστικό εκπαιδευτικό εργαλείο αστέρα–τριγώνου (Υ/Δ), σχεδιασμένο για φοιτητές Ηλεκτρολόγων Μηχανικών. **Όλα τα σενάρια είναι προσομοιωμένα· δεν προορίζεται για πραγματική καλωδίωση υπό τάση ή επαλήθευση προστασιών.**

## Ξεκίνημα / Εκτέλεση

1. Κάνε αποσυμπίεση του ZIP.
2. **Διπλό κλικ στο `index.html`** ή `standalone.html` σε Chrome, Firefox ή Edge. Δεν χρειάζεται Internet, npm ή Python server.
3. Για το GitHub Pages: ανέβασε **όλο τον φάκελο** σε GitHub repository και από Settings → Pages → Deploy from branch → `main` / `(root)`. Το `index.html` της ρίζας είναι πλήρως αυτοτελές. Μπορείς εναλλακτικά να χρησιμοποιήσεις το προετοιμασμένο GitHub Actions workflow ή τον φάκελο `dist`.
4. Για ανάπτυξη/αλλαγές source: Node.js 18+, ``npm run build` (δημόσια χωρίς quiz), `npm test`. Η χρήση του `src` ως ES modules απαιτεί local server (`npm run dev`). Το **έτοιμο `index.html` δεν απαιτεί server**.

## Επιλογή έκδοσης

- **FULL:** με ενότητα «Εξάσκηση», 36 ερωτήσεις, εξήγηση απαντήσεων και εξαγωγή CSV/JSON.
- **PUBLIC:** χωρίς εμφανή ενότητα quiz και χωρίς δεδομένα ερωτήσεων (`src/quiz.js` είναι άδειο). Σχεδιασμένη για Discord, GitHub Pages και δημόσια διανομή. Όλα τα υπόλοιπα είναι ίδια.

## Πέντε βασικά σενάρια

1. **Κανονικό Υ/Δ:** Schematic editor → `AUTO: έτοιμο Υ/Δ`. Η δομή περιέχει 18 αγωγούς. Σύρε από έναν κυκλικό ακροδέκτη στον άλλον. Επίλεξε αγωγό για αλλαγή/διαγραφή. Ο γράφος ενημερώνει τις κοινές ηλεκτρικές συνδέσεις και το δεξί σχήμα.
2. **Σταδιακή συναρμολόγηση:** `Κενό κύκλωμα`, στη συνέχεια `Πρόσθεσέ το` ή σύνδεση μέσω drag. Οι αγωγοί εμφανίζονται και στους δύο συγχρονισμένους καμβάδες με zoom/pan.
3. **Δύο θέσεις F3:** στη γραμμή (`Iₙ`) ή μέσα στον βρόχο Δ (`Iₙ/√3≈0,58 Iₙ`). Η αλλαγή της θέσης **επαναφέρει σωστή καλωδίωση προτύπου** και ξαναυπολογίζει τις τιμές. Πάντα απαιτείται έλεγχος και συντονισμός προστασιών από προδιαγραφές κατασκευαστή.
4. **Κανονική εκκίνηση:** `AUTO: έτοιμο Υ/Δ` → Κυματομορφές → φορτίο `0–100%` → `START`. Ο K3M κλείνει πρώτος και η εσωτερική μπάρα βραχυκυκλώνει (ενώνει στον ίδιο κοινό κόμβο) τα U2, V2, W2. Μετά το χρονικό/κριτήριο, μεσολαβεί νεκρός χρόνος, μετά οπλίζει K2M και η σύνδεση γίνεται Δ.
5. **Χωρίς αστέρα (ειδική δοκιμή):** `AUTO: χωρίς κλάδο Υ` ή διέγραψε **όλα** τα τρία καλώδια προς K3M. Ο K3M μπορεί να οπλίζει και να ενεργοποιεί το μηχανικά προσαρμοσμένο χρονικό, αλλά τα άκρα U2/V2/W2 **δεν γίνονται κοινός κόμβος**. Σε Υ ο κινητήρας παραμένει ακίνητος. Μόνο όταν ολοκληρωθεί ο χρονισμός, κλείνει Δ και ο κινητήρας υφίσταται **απευθείας εκκίνηση Δ με χρονική καθυστέρηση** (υψηλό ρεύμα). Αν επιλεγεί μόνο κριτήριο ταχύτητας, η δοκιμή μπλοκάρεται επειδή το κατώφλι δεν μπορεί να επιτευχθεί.

## Διαβάζοντας την ενότητα «Κυματομορφές & ροπή»

- Κύριο ρυθμιστικό φορτίου **0–100%**. Σταθερή ροπή φορτίου ή ανεμιστήρας προσεγγιστικά `TL∝n²`.
- RMS ρεύμα, ροπή, ταχύτητα, ολίσθηση σε χρόνο. Τριφασικά ημιτονοειδή ρεύματα σε παράθυρο 120 ms, με πλάτος που αλλάζει ανάλογα με την ολίσθηση — **χωρίς πραγματικό electromagnetic transient solver**.
- Διαδραστικό διάγραμμα `Te(s)` σε Υ και Δ και αναφορά στις περιοχές μικρής ολίσθησης / ανατροπής / ακινητοποιημένου δρομέα.
- Ισοδύναμο ανά φάση: `R1+jX1`, παράλληλοι κλάδοι `jXm` και `R2'/s+jX2'`· παράμετροι `R1,X1,R2',X2',Xm,J`. Ο χρήστης μπορεί να τροποποιεί τις εκπαιδευτικές παραμέτρους.
- Εξίσωση κίνησης: `J dω/dt = Te - TL - Bω`, `s=(ωs-ω)/ωs` και `ns=120 f/p`.
- **Προσοχή:** το μαθηματικό ισοδύναμο και οι μηχανικές αποκρίσεις είναι προσεγγιστικές. Δεν προσομοιώνονται πραγματικά ηλεκτρομαγνητικά μεταβατικά (dc-offset, κορεσμός, υψηλές αρμονικές, transients επαφών). Η συνδεσιμότητα στον editor προκύπτει από γράφο, ενώ ο δυναμικός solver είναι ξεχωριστό μοντέλο ισοζυγίου ροπών. Δεν υπολογίζονται ρεύματα βραχυκυκλώματος ή μελέτη συντονισμού προστασιών.

## Κύκλωμα αυτοματισμού

- `K1M` κύριος, `K2M` Δ, `K3M` Υ.
- Στη συγκεκριμένη παραλλαγή του εργαστηρίου το χρονικό **δεν διαθέτει δικό του πηνίο**: είναι μηχανικά προσαρτημένο στο K3M. Το K3M εμφανίζει δύο βοηθητικές επαφές (NO + NC) και δύο χρονικές επαφές (NO + NC). Η εκπαιδευτική χρήση του K4M ως memory αποτρέπει ανεπιθύμητη επαναφορά της ακολουθίας.
- Εναλλακτική: ανεξάρτητο χρονικό `KT1` με πηνίο A1/A2 ή μετάβαση με βάση `n/nₛ`.
- Οι επαφές/λογικές καταστάσεις είναι εκπαιδευτικό control sequence και **όχι ακόμη γενικός επιλυτής αυθαίρετης ladder καλωδίωσης**.

## Δομή project

`src/main.js`: React UI. `src/engine/topology.js`: ηλεκτρικός γράφος και απλοποιημένο στατικό ανά τύλιγμα κύκλωμα. `src/engine/motor-dynamics.js`: εκπαιδευτικός Thevenin + μηχανική ολοκλήρωση. `styles.css`: διεπαφή. `src/quiz.js`: δεδομένα quiz (μόνο FULL). `tools/build.mjs`: πακετάρισμα offline HTML. `tests/`: αυτοματοποιημένα tests.
